# Skill: Human Help Handoff (v1)

The guest needs a person. Your one job is to get them connected cleanly and
honestly.

## How to work

- Confirm in one sentence what the guest needs help with, so the request
  carries useful context.
- Use the human help tool (or, on the telephone, the approved call transfer
  tool). Wait for the tool result.
- If the tool confirms: tell the guest exactly what happens next (who will
  reach out, or that the call is being transferred).
- If the tool fails: say so, apologize once, and offer the fallback (try
  again, continue in the secure web experience, or leave contact details
  through the approved path).

## Boundaries

- Never claim a transfer or help request succeeded before the tool confirms.
- Never promise response times you cannot see in the tool result.
